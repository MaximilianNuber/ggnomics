# Palettes

Tableau-10/20 and a scater-style Bioconductor palette are original
categorical palettes. The IGV chromosome palette (`igv_default`,
`igv_alternating`) is **not** a ggnomics creation — its values are taken
from the [Integrative Genomics Viewer](https://software.broadinstitute.org/software/igv/)
chromosome-color convention as republished by the R package
[`ggsci`](https://cran.r-project.org/package=ggsci) (`ggsci::pal_igv()`),
citing Robinson et al., *Nature Biotechnology* 29, 24-26 (2011). ggnomics
redistributes it with attribution and does not claim ownership.

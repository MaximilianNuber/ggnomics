ggnomics

Composable, ggplot2-style genomics visualization for Python

ggnomics provides ggplot2-style visualizations for bulk, single-cell, and multimodal genomics in Python. Its plotting functions work with tidy pandas data and common genomics containers, including AnnData and BiocPy’s SingleCellExperiment and SummarizedExperiment.

The result is a plotnine plot that remains yours to adapt:

import ggnomics as gg
import plotnine as p9

p = gg.plot_umap(adata, color="cluster")
p + p9.theme_bw() + p9.labs(title="Cell populations")

Start with Getting started, follow one of the end-to-end workflows, or browse the plot gallery for a particular figure.

What’s supported

Container Package Typical use
pd.DataFrame pandas Tidy plotting tables and model results
AnnData anndata / scverse Single-cell data in scverse workflows
SingleCellExperiment BiocPy singlecellexperiment Single-cell assays, metadata, and reduced dimensions
SummarizedExperiment BiocPy summarizedexperiment Bulk assays and sample metadata
MuData mudata / scverse Measurements across several modalities

Because SummarizedExperiment does not store reduced dimensions, embedding plots require either explicit coordinates or a richer container. For bulk assays, ggnomics.bulk_pca computes and plots PCA scores directly. The Getting started guide shows the supported paths in more detail.

One plotting interface

The public plot_* functions use Python’s singledispatch: the function name and main arguments stay the same while the input container determines how data are extracted. The DataFrame implementation supplies the public docstring shown by help() and in Jupyter. Adapters for AnnData, BiocPy, and MuData register automatically when their corresponding packages are installed.

Getting started §7 explains the design and shows how to inspect the registered implementations.

Build on the returned plot

Most functions return an ordinary ggplot, so plotnine layers, scales, themes, coordinates, and labels can be added directly. This keeps the convenient genomics defaults without limiting the final figure.

p = gg.plot_umap(adata, color="cluster")
p + p9.theme_bw() + p9.labs(title="My figure")

Multi-panel functions such as plot_pseudobulk_qc, plot_scatter_marginal, and plot_embedding_panel return a plotnine.composition.Compose. They can be arranged with plotnine’s | and / operators or with ggnomics helpers such as hstack, vstack, and grid.

Optional backends

The core installation provides the DataFrame interface. Container-specific support can be added through optional extras:

pip install "ggnomics[anndata]"    # AnnData / scverse
pip install "ggnomics[sce]"        # SingleCellExperiment (BiocPy)
pip install "ggnomics[se]"         # SummarizedExperiment (BiocPy)
pip install "ggnomics[multimodal]" # MuData
pip install "ggnomics[stats]"      # significance brackets (scipy, statsmodels)
pip install "ggnomics[pca]"        # PCA utilities
pip install "ggnomics[umap]"       # ggnomics.sc_umap
pip install "ggnomics[all]"        # everything above

The workflow guides also use scranpy, PyDESeq2, Marsilea, scrnaseq, pyexpressionatlas, and experimenthub. These are analysis or data-access packages used alongside ggnomics rather than runtime dependencies of the plotting library.

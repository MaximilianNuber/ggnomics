ggnomics.repertoire.plot_clonotype_abundance 

plot_clonotype_abundance(data: DataFrame, clonotype_col: str, sample_col: Optional[str] = None, top_n: int = 20, expansion_col: Optional[str] = None, expansion_thresholds: Optional[Dict[int, str]] = None, palette: Optional[Dict] = None, facet_by: Optional[str] = None, title: Optional[str] = None) -> ggplot

Barplot of clonotype abundance colored by expansion category.

x-axis: clonotype rank (1 = most abundant, computed within each facet group when facet_by/sample_col is given). y-axis: cell count. Fill: expansion category (computed from clone sizes if expansion_col is None).

Parameters:
  • data (DataFrame) –

    DataFrame whose rows are cells. clonotype_col and any of sample_col/expansion_col/facet_by are columns.

  • clonotype_col (str) –

    Column holding clonotype identifiers (NaN for cells without a clonotype).

  • sample_col (Optional[str], default: None ) –

    Column used to facet the plot, and to rank/count clonotypes within each sample rather than globally. Ignored if facet_by is also given (facet_by takes precedence).

  • top_n (int, default: 20 ) –

    Number of top clonotypes to show per facet. Must be >= 1.

  • expansion_col (Optional[str], default: None ) –

    Column with a precomputed expansion category. When None, categories are computed from clone sizes.

  • expansion_thresholds (Optional[Dict[int, str]], default: None ) –

    {min_clone_size: category_label} mapping. Defaults to the scRepertoire-style thresholds.

  • palette (Optional[Dict], default: None ) –

    {category: hex} fill color mapping. Defaults to the built-in expansion palette.

  • facet_by (Optional[str], default: None ) –

    Column used to facet the plot (and to rank within each facet). Defaults to sample_col when omitted.

  • title (Optional[str], default: None ) –

    Plot title.
Returns:
  • ggplot –

    A plotnine.ggplot object.
Raises:
  • TypeError –

    If no implementation is registered for type(data).

  • ValueError –

    If top_n < 1.

  • KeyError –

    If a requested column is absent.

Embedding plot colored by clonotype expansion category.

Cells without a clonotype (NaN in clonotype_col) are drawn first (underneath expanded clones) in non_tcell_color.

Parameters:
  • data (DataFrame) –

    DataFrame with embedding columns matched against dimred (see :func:ggnomics.plot_embedding) plus clonotype_col.

  • clonotype_col (str) –

    Column holding clonotype identifiers.

  • dimred (str, default: 'X_umap' ) –

    Embedding key (e.g. "X_pca", "X_umap").

  • components (Tuple[int, int], default: (1, 2) ) –

    One-indexed (x, y) component pair to plot.

  • expansion_thresholds (Optional[Dict[int, str]], default: None ) –

    {min_clone_size: category_label} mapping.

  • non_tcell_color (str, default: '#DDDDDD' ) –

    Fill color for cells without a clonotype.

  • palette (Optional[Dict], default: None ) –

    {category: hex} mapping overriding the default expansion palette.

  • size (Optional[float], default: None ) –

    Point size (None -> adaptive).

  • stroke (Optional[float], default: None ) –

    Point stroke width (None -> adaptive).

  • alpha (float, default: 0.8 ) –

    Point transparency.

  • title (Optional[str], default: None ) –

    Plot title.
Returns:
  • ggplot –

    A plotnine.ggplot object.
Raises:
  • TypeError –

    If no implementation is registered for type(data).

  • KeyError –

    If clonotype_col or the embedding is not found.

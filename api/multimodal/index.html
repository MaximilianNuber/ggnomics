ggnomics.multimodal.plot_bimodal_scatter 

plot_bimodal_scatter(data: DataFrame, x_feature: str, y_feature: str, x_mod: str = 'rna', y_mod: str = 'prot', color: Optional[str] = None, size: Optional[float] = None, stroke: Optional[float] = None, alpha: float = 0.7, layer_x: Optional[str] = None, layer_y: Optional[str] = None, add_marginal: bool = False, palette: Optional[Dict] = None, cmap: str = 'viridis', title: Optional[str] = None, x_label: Optional[str] = None, y_label: Optional[str] = None) -> 'Union[ggplot, Compose]'

Scatter plot of two features, typically from different modalities.

Designed for CITE-seq-style data (e.g. RNA vs surface protein). If add_marginal=True, delegates to :func:ggnomics.plot_scatter_marginal and returns a plotnine.composition.Compose instead of a ggplot.

Parameters:
  • data (DataFrame) –

    DataFrame whose rows are cells. x_feature, y_feature, and color are ordinary columns in the same DataFrame.

  • x_feature (str) –

    Column mapped to the x-axis.

  • y_feature (str) –

    Column mapped to the y-axis.

  • x_mod (str, default: 'rna' ) –

    Present for cross-container signature consistency (selects the modality/layer for x_feature in AnnData/MuData). Has no effect for a plain DataFrame.

  • y_mod (str, default: 'prot' ) –

    Same as x_mod for y_feature.

  • color (Optional[str], default: None ) –

    Optional column mapped to point color.

  • size (Optional[float], default: None ) –

    Point size (None -> adaptive).

  • stroke (Optional[float], default: None ) –

    Point stroke width (None -> adaptive).

  • alpha (float, default: 0.7 ) –

    Point transparency.

  • layer_x (Optional[str], default: None ) –

    Present for cross-container signature consistency. Has no effect for a plain DataFrame.

  • layer_y (Optional[str], default: None ) –

    Same as layer_x for y_feature.

  • add_marginal (bool, default: False ) –

    Return a scatter-with-marginals composition instead of a bare scatter plot.

  • palette (Optional[Dict], default: None ) –

    {category: hex} color mapping.

  • cmap (str, default: 'viridis' ) –

    Matplotlib colormap for a continuous color.

  • title (Optional[str], default: None ) –

    Plot title.

  • x_label (Optional[str], default: None ) –

    Override x-axis label (defaults to x_feature).

  • y_label (Optional[str], default: None ) –

    Override y-axis label (defaults to y_feature).
Returns:
  • 'Union[ggplot, Compose]' –

    A plotnine.ggplot object, or a plotnine.composition.Compose when add_marginal=True.
Raises:
  • TypeError –

    If no implementation is registered for type(data).

  • KeyError –

    If a requested column is absent.

ggnomics.multimodal.plot_adt_qc 

plot_adt_qc(data: DataFrame, isotype_controls: List[str], layer: Optional[str] = None, group_by: Optional[str] = None, log1p: bool = True, palette: Optional[Dict] = None, ncol: int = 3, title: Optional[str] = None, features: Optional[List[str]] = None, *, mod: str = 'prot') -> ggplot

ADT / protein QC: overlay isotype-control distributions on real antibodies.

For each real antibody, shows a density curve. Overlays the pooled isotype-control distribution as a shaded fill. If group_by is provided, facets by that column.

Parameters:
  • data (DataFrame) –

    DataFrame whose rows are cells. features are the antibody expression columns; group_by is a metadata column.

  • isotype_controls (List[str]) –

    Non-empty list of isotype-control feature names. Must be a subset of features.

  • layer (Optional[str], default: None ) –

    Present for cross-container signature consistency. Has no effect for a plain DataFrame, which has no concept of layers.

  • group_by (Optional[str], default: None ) –

    Optional column used to facet the plot. Raises KeyError if supplied but absent (never silently ignored).

  • log1p (bool, default: True ) –

    Log1p-transform expression before plotting.

  • palette (Optional[Dict], default: None ) –

    {antibody: hex} color mapping.

  • ncol (int, default: 3 ) –

    Facet columns when group_by is given.

  • title (Optional[str], default: None ) –

    Plot title.

  • features (Optional[List[str]], default: None ) –

    The antibody feature columns (real antibodies plus isotype controls). Required for a DataFrame — metadata columns are never guessed as antibodies.

  • mod (str, default: 'prot' ) –

    Keyword-only. MuData modality to use (default "prot"). Ignored for a plain DataFrame.
Returns:
  • ggplot –

    A plotnine.ggplot object.
Raises:
  • TypeError –

    If no implementation is registered for type(data).

  • ValueError –

    If isotype_controls is empty, features is omitted for a DataFrame, or no real antibody features remain.

  • KeyError –

    If a requested column/feature is absent.

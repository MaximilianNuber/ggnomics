ggnomics.expression.plot_expression 

plot_expression(data: DataFrame, features: List[str], group_by: str, layer: Optional[str] = None, color_by: Optional[str] = None, palette: Optional[Dict] = None, ncol: Optional[int] = None, log1p: bool = False, add_points: bool = False, point_size: Optional[float] = None, title: Optional[str] = None) -> ggplot

Violin plot of feature expression across cell/sample groups.

Each feature becomes one facet panel; the x-axis shows group_by categories and the y-axis shows expression level.

Parameters:
  • data (DataFrame) –

    DataFrame whose rows are cells/samples. Requested features and group_by/color_by are columns.

  • features (List[str]) –

    Non-empty list of feature/gene column names to plot. Must not contain duplicates or collide with group_by/color_by.

  • group_by (str) –

    Column whose categories define the x-axis groups.

  • layer (Optional[str], default: None ) –

    Present for cross-container signature consistency. Has no effect for a plain DataFrame, which has no concept of layers.

  • color_by (Optional[str], default: None ) –

    Column to map to fill color. Defaults to group_by.

  • palette (Optional[Dict], default: None ) –

    {category: hex} color mapping.

  • ncol (Optional[int], default: None ) –

    Number of columns in facet_wrap layout.

  • log1p (bool, default: False ) –

    If True, log1p-transform expression values before plotting.

  • add_points (bool, default: False ) –

    Overlay jittered points on violins.

  • point_size (Optional[float], default: None ) –

    Size of jittered points (None → adaptive).

  • title (Optional[str], default: None ) –

    Plot title.
Returns:
  • ggplot –

    A plotnine.ggplot object.
Raises:
  • TypeError –

    If no implementation is registered for type(data).

  • ValueError –

    If features is empty, contains duplicates, or collides with group_by/color_by.

  • KeyError –

    If a requested column is absent.

ggnomics.expression.plot_dot 

plot_dot(data: DataFrame, features: List[str], group_by: str, layer: Optional[str] = None, scale: bool = True, dot_max: float = 1.0, dot_min: float = 0.0, col_min: float = -2.5, col_max: float = 2.5, palette: str = 'viridis', title: Optional[str] = None) -> ggplot

Classic dot plot: mean expression (color) and fraction expressing (size).

Each dot's color encodes the mean expression of that feature in that group; dot size encodes the fraction of cells with non-zero expression.

Parameters:
  • data (DataFrame) –

    DataFrame whose rows are cells/samples. Requested features and group_by are columns.

  • features (List[str]) –

    Non-empty list of feature/gene column names to display (y-axis). Must not contain duplicates or collide with group_by.

  • group_by (str) –

    Column for groups (x-axis).

  • layer (Optional[str], default: None ) –

    Present for cross-container signature consistency. Has no effect for a plain DataFrame, which has no concept of layers.

  • scale (bool, default: True ) –

    If True, scale mean expression per gene to [col_min, col_max] before plotting.

  • dot_max (float, default: 1.0 ) –

    Maximum dot size (mapped to 100% expressing).

  • dot_min (float, default: 0.0 ) –

    Minimum dot size.

  • col_min (float, default: -2.5 ) –

    Clip scaled expression below this value.

  • col_max (float, default: 2.5 ) –

    Clip scaled expression above this value.

  • palette (str, default: 'viridis' ) –

    Matplotlib colormap name for the color scale.

  • title (Optional[str], default: None ) –

    Plot title.
Returns:
  • ggplot –

    A plotnine.ggplot object.
Raises:
  • TypeError –

    If no implementation is registered for type(data).

  • ValueError –

    If features is empty, contains duplicates, or collides with group_by.

  • KeyError –

    If a requested column is absent.

plot_coldata(data: DataFrame, x: str, y: str, color_by: Optional[str] = None, size: Optional[float] = None, shape: str = 'point', palette: Optional[Dict] = None, facet_by: Optional[str] = None, title: Optional[str] = None) -> ggplot

Plot columns from a cell- or sample-metadata DataFrame.

Both numeric columns produce a scatter plot. With a categorical x, shape selects a point, violin, box, or bar geometry. Container-specific implementations convert their column metadata to a DataFrame and then use this implementation.

Parameters:
  • data (DataFrame) –

    DataFrame whose rows are observations and columns are metadata.

  • x (str) –

    Column mapped to the x-axis.

  • y (str) –

    Column mapped to the y-axis.

  • color_by (Optional[str], default: None ) –

    Optional column mapped to color or fill.

  • size (Optional[float], default: None ) –

    Point size. None chooses a size from the number of rows.

  • shape (str, default: 'point' ) –

    One of "point", "violin", "box", or "bar".

  • palette (Optional[Dict], default: None ) –

    Optional {category: color} mapping.

  • facet_by (Optional[str], default: None ) –

    Optional column used to facet the plot.

  • title (Optional[str], default: None ) –

    Optional plot title.
Returns:
  • ggplot –

    A plotnine.ggplot object.
Raises:
  • TypeError –

    If no implementation is registered for type(data).

  • KeyError –

    If a requested column is absent.

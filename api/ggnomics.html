ggnomics.geom_signif(comparisons=None, annotations=None, y_position=None, xmin=None, xmax=None, test='mannwhitney', test_args=None, map_signif_level=True, p_adjust='bonferroni', margin_top=0.05, step_increase=0.1, tip_length=0.03, bracket_nudge_y=0.0, textsize=15, vjust=-10, color='black', linetype='solid', linewidth=0.5, sig_only=False, orientation='x')¶

Add significance brackets to a plotnine violin/box/bar plot.

Returns a list of plotnine layers (manual mode) or a _DeferredSignif object (automatic mode) that can be resolved with .resolve(df, x_col, y_col).

Manual mode. When annotations + y_position + xmin + xmax are all provided, draws brackets at the exact positions given without running any statistics:

geom_signif(
    annotations=["p = 0.003"],
    y_position=[8.5],
    xmin=[1],
    xmax=[3],
)

Automatic mode. When only comparisons are given, returns a _DeferredSignif that runs statistical tests at resolve time:

deferred = geom_signif(comparisons=[("A", "B"), ("A", "C")])
layers = deferred.resolve(df, x_col="group", y_col="value")
for layer in layers:
    p = p + layer
Parameters:

  • comparisons (list of (group_a, group_b))

  • annotations (list of str — pre-computed labels (manual mode))

  • y_position (list of float — bracket bar y positions (manual mode))

  • xmin (list of float — bracket x spans, numeric (manual mode))

  • xmax (list of float — bracket x spans, numeric (manual mode))

  • test ("mannwhitney" | "wilcoxon" | "ttest" | "kruskal")

  • map_signif_level (True | False | dict | callable) –

    How p-values become labels:

    True     → default star mapping
False    → "p={value:.3f}"
dict     → {threshold: label}
callable → f(p) → str

  • p_adjust ("bonferroni" | "fdr_bh" | "none")

  • margin_top (fraction of y range above data max before first bracket)

  • step_increase (fraction of y range added per stacked bracket)

  • tip_length (fraction of y range for vertical tips; [left, right] for asymmetric)

  • sig_only (if True, only draw brackets with adjusted p < 0.05)

  • orientation ("x" (vertical plots) | "y" (horizontal plots, experimental))

ggnomics.map_pvalue_to_stars(p, mapping=None)¶

Convert a p-value to a significance label.

Default thresholds match ggsignif:

p <= 0.0001 → "****"
p <= 0.001  → "***"
p <= 0.01   → "**"
p <= 0.05   → "*"
p >  0.05   → "ns"
Parameters:

  • p (float) – p-value.

  • mapping (dict | None, default: None) – Custom {threshold: label} dict. Thresholds are tested in ascending order; the first threshold for which p <= threshold is returned.

ggnomics.plot_violin_stats(data, feature, group_by, layer=None, comparisons=None, test='mannwhitney', p_adjust='bonferroni', sig_only=True, annotation='stars', add_boxplot=True, add_points=False, point_size=None, palette=None, order=None, x_label=None, y_label=None, title=None, dodge=False)

Violin plot with automatic statistical significance annotations.

Runs pairwise tests between groups defined by comparisons (or all pairs when the number of groups is <= 5 and comparisons is None). Draws significance brackets as geom_segment/geom_text layers via ggnomics.signif.geom_signif(), using proportional spacing (fractions of the y-range) so brackets look correct regardless of data scale.

Parameters:

  • data (DataFrame) – DataFrame whose rows are cells/samples. feature and group_by are columns.

  • feature (str) – Column holding the numeric value to plot. For a plain DataFrame this is simply a column; container adapters may also resolve it against an expression feature.

  • group_by (str) – Column whose categories define the x-axis groups.

  • layer (Optional[str], default: None) – Present for cross-container signature consistency. Has no effect for a plain DataFrame, which has no concept of layers.

  • comparisons (Optional[List[Tuple]], default: None) – Explicit list of (group_a, group_b) tuples to test. None auto-generates all pairs when there are <= 5 groups.

  • test (str, default: 'mannwhitney') – One of the tests supported by ggnomics.signif.run_comparisons().

  • p_adjust (str, default: 'bonferroni') – Multiple-testing correction method.

  • sig_only (bool, default: True) – Only draw brackets for significant comparisons.

  • annotation (str, default: 'stars') – "stars", "pvalue", "padj", or a callable mapping a p-value to a label.

  • add_boxplot (bool, default: True) – Overlay a narrow boxplot on each violin.

  • add_points (bool, default: False) – Overlay jittered points.

  • point_size (Optional[float], default: None) – Jittered point size (None → adaptive).

  • palette (Optional[Dict], default: None) – {category: hex} fill color mapping.

  • order (Optional[List], default: None) – Explicit group ordering (unlisted groups appended at the end).

  • x_label (Optional[str], default: None) – Override x-axis label (defaults to group_by).

  • y_label (Optional[str], default: None) – Override y-axis label (defaults to feature).

  • title (Optional[str], default: None) – Plot title.

  • dodge (bool, default: False) – Reserved for future grouped-violin support.

Return type:

plotnine.ggplot

Returns:

A plotnine.ggplot object.

Raises:

  • TypeError – If no implementation is registered for type(data).

API reference

Reduced dimensions

plot_embedding Plot embedding columns from a pandas DataFrame.
plot_reduced_dim
plot_umap Plot the first two dimensions of the X_umap embedding.
plot_pca Plot selected dimensions of the X_pca embedding.
plot_tsne Plot the first two dimensions of the X_tsne embedding.

Expression and metadata

plot_expression Violin plot of feature expression across cell/sample groups.
plot_coldata Plot columns from a cell- or sample-metadata DataFrame.
plot_rowdata Scatter-plot columns from a feature-metadata DataFrame.
plot_dot Classic dot plot: mean expression (color) and fraction expressing (size).
plot_highest_exprs Boxplot of the top-n highest-expressed genes.

Abundance and composition

plot_abundance Plot category composition from an observation-metadata DataFrame.

Heatmaps

plot_heatmap Gene-expression heatmap using geom_tile.

Differential expression

plot_volcano Volcano plot from a DE results DataFrame.
plot_ma MA plot (mean expression vs log fold change).
plot_coef_lollipop Horizontal lollipop plot of model coefficients.
plot_coef_expression Plot expression of top-n features from a coefficient table.

Pseudobulk

plot_pseudobulk_qc Three-panel QC figure for pseudobulk analysis setup.
plot_pseudobulk_de Visualise DE results across multiple clusters or contrasts.

Multimodal

plot_bimodal_scatter Scatter plot of two features, typically from different modalities.
plot_adt_qc ADT / protein QC: overlay isotype-control distributions on real antibodies.

Immune repertoire

plot_clonotype_abundance Barplot of clonotype abundance colored by expansion category.
plot_clonotype_overlap Heatmap of pairwise clonotype overlap between samples.
plot_clonotype_embedding Embedding plot colored by clonotype expansion category.

Statistics

plot_violin_stats Violin plot with automatic statistical significance annotations.
plot_box_stats Box plot with automatic statistical significance annotations.
geom_signif Add significance brackets to a plotnine violin/box/bar plot.
run_comparisons Run pairwise statistical tests for specified comparisons.
